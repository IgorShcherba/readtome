# Read To Me

A playground where I experiment with [Exact](https://github.com/expo/exact).

The app turns a web link or a PDF into audio you can listen to, using OpenAI text-to-speech.
It runs on the web and iOS.

- `app.contract`: the view
- `app.ts`: its data module
- `app.test.contract`: the tests
- `app.json`: the manifest

It expects an Exact checkout at `../exact`.
